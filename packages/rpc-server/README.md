# @typerighter/rpc-server

![Binary Size](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/huydo862003/typerighter/main/.github/badges/binary-size.json)

Platform-specific binary package for the Typedown RPC server. Downloads the correct `typedown-lsp` binary for your OS and architecture on `postinstall`.

This package is a dependency of `typerighter` and is not typically installed directly.
