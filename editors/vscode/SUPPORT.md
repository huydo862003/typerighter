# Support

If you run into issues or have questions about the Typerighter VS Code extension, here is how to get help.

## Report a bug

Open an issue on the [GitHub issue tracker](https://github.com/huydo862003/typerighter/issues).

Include the VS Code version, extension version, and steps to reproduce the problem.

## Feature requests

Feature requests are welcome as GitHub issues. Tag them with `enhancement`.
